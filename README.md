# Be Prepared — Browser Beta v0.1

A standalone, local-first preparedness and continuity-map prototype. Open `index.html` in a modern browser. No installation, account, backend, or internet connection is required.

## Principles

- People → Situations → Preparedness.
- The 5Q Check stores only whether something exists, where it is, who handles it, who else knows, and when it was last confirmed.
- Completeness is not readiness. Scores emphasize critical coverage, directions, shared knowledge, and recency.
- Do not enter passwords, account numbers, medical details, medications, documents, or document contents.
- Data and product events stay in browser `localStorage`; nothing is transmitted.

## Included

Scenario-led navigation, multi-person maps, seven domains, person × scenario scoring, top gaps, simulated local handoff contacts and Handoff Test, overdue check-ups, search, Emergency View, print/PDF styling, JSON backup import/export, optional demo data, reset, privacy/about information, and local future-service feedback.

## Deferred to Continuity SaaS v1

Accounts, cross-device sync, real trusted-contact invitations, identity verification, cloud reminders, Prepared ID issuance, controlled handoff and safety windows, email/SMS, provider integrations, server analytics, collaboration, cloud key management, and dead-man switches. Medical, financial, legal, document-storage, and password-management features are deliberately out of scope.

This prototype is not an emergency service or medical, financial, insurance, or legal adviser. JSON backups can contain personal location hints; store them appropriately.
